# Data dictionary

## Input workbooks (`data/input/*.xlsx`, sheet "Comments")
`Source` (channel, e.g. "Reddit r/CommBank", "Google Play", "Apple App Store (AU)", "Hacker News"), `UserID`, `Date` (2025-01-01..2026-11-21), `Comment`, `Reply`, `Rating` (1-5 or blank).
Rows: CBA 10,413; ANZ 4,032; NAB 3,233; Westpac 3,289. Reddit dominates volume and spikes in Oct-Nov 2026.

## Tagged data (`artifacts/tagged-data/`)
`tagged_cba.csv`, `tagged_competitors.csv` = input columns (UserID/Reply removed) + `Account Type`, `Primary Area`, `Secondary Area`, `Sentiment` (+ `Bank` for competitors).
These are exactly what the prototype scripts used to build the workbook and app. Final counts (CBA): Business 182 / Personal 2,332 / General 7,899; competitors Business 142.

## Workbook sheets (`artifacts/workbook/commbank-user-comments-analysed.xlsx`)
- `Method & Notes` - how each column was derived and limitations.
- `Comments` - original columns A-F + G Account Type, H Primary Area, I Secondary Area, J Sentiment, K Areas for improvement, L What competitors are offering.
- `Summary` - original.
- `Competitor Reference` - per area: CBA/ANZ/NAB/Westpac counts and %pos/%neg, CBA positives/negatives, competitor summary.
- `Intel - Business Only`, `Intel - Business + General` - per area stats, strongest competitor, intelligence, opportunity, competitor mobile features, mobile suggestions (+ supporting comments to the right on the Business-only tab).
- `Mobile App Feature Matrix` - 35 features x ANZ/NAB/Westpac(NZ) with sources.

## Pipeline files
See `docs/data-contract.md` (raw -> interim -> processed -> reports).

## UI data bundle (`<script id="data" type="application/json">`)
`banks, accts, sents, areas, months, srcs` (lookup lists) ; `agg [bank,area,acct,sent,n]` ; `trend [bank,month,acct,sent,n]` ; `trendArea [area,month,acct,sent,n]` (CBA) ;
`rating [bank,month,sum,n]` ; `ratingArea [area,sum,n]` ; `src [bank,source,sent,n]` ; `cba [date,source,rating,acct,area,sent,text]` ;
`ex` (example comments per bank|area) ; `text` (per-area playbook text) ; `cls` (taxonomy + segment regexes for in-browser classification) ; `matrix` (feature rows) ; `asof, other`.
Generated by `src/ci/ui/export_data.py`.
